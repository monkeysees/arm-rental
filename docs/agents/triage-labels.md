# Triage labels

| Role            | Tracker label   | Meaning                                              |
| --------------- | --------------- | ---------------------------------------------------- |
| needs-triage    | needs-triage    | Needs maintainer evaluation                          |
| needs-info      | needs-info      | Waiting for more information                         |
| ready-for-agent | ready-for-agent | Specified for agent implementation; respect blockers |
| ready-for-human | ready-for-human | Requires human implementation                        |
| wontfix         | wontfix         | Will not be implemented                              |

Use this mapping whenever a skill refers to a triage role.
